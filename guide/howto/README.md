# how-to — 目的から引く

仕事の途中で開く頁である。目的を先頭に置き、手順だけを書く。理由と背景は書かない — 概念は [concepts.md](../concepts.md)、規範は [spec/](../../spec/) が持つ。

koyu にはじめて触れるなら、まず [start.md](../start.md) を通しで書くこと。how-to は基本を知っている読者を前提にしている。

| したいこと | 頁 |
|---|---|
| 階を足し、階段でつなぎ、矩計と到達性で確かめる | [add-a-level.md](add-a-level.md) |
| 一室の住戸を間取りに割る (`zone` と `space` の使い分け) | [unit-layout.md](unit-layout.md) |
| 窓を開けて `light` の 1/7 判定を通す | [daylight.md](daylight.md) |
| 扉をつなぎ、避難経路と到達性を確かめる | [doors-and-escape.md](doors-and-escape.md) |
| 敷地形状を与え、接道・建蔽率・容積率を出す | [site-and-far.md](site-and-far.md) |
| `import` で一棟を複数ファイルに割り、分担して書く | [split-into-files.md](split-into-files.md) |
| エージェント (MCP) から koyu を読み書きさせる | [agent-mcp.md](agent-mcp.md) |
| エディタで色を付け、保存のたびに check を走らせる | [editor.md](editor.md) |
| エラー・警告が出たときに原因まで降りる | [troubleshooting.md](troubleshooting.md) |

診断コードから原因と直し方を引くときは [diagnostics.md](../diagnostics.md)、記法を一枚で見渡すときは [cheatsheet.md](../cheatsheet.md) を使う。
