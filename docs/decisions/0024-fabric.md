# ADR-0024: 床・天井・屋根は語彙を増やさずに現れる — ただし天井は近似であると認める

日付: 2026-07-26 / 状態: 採用 (言語版0.5) / 起点: 「天井や屋根がないのはよろしくない。Revitのシステムファミリをカバーしていこう」

## 文脈

0.5 で壁・開口・階段・斜路・エスカレーター・昇降機・手すり・柱が揃った。それでも Revit のシステムファミリと並べると穴が二つ残っていた — **天井と屋根**である。床も、2.5D の積層表示ではプレートとして描かれていたが、3D の実体としては存在していなかった。

図として見たときこの穴は決定的だった。壁と柱だけの立体は「建物」に見えない。床が無いので各階が浮き、屋根が無いので基壇の上が抜けている。

同時に、要素を足すたびに語彙を増やしていては ADR-0021/0023 が積み上げた規律が崩れる。

## 決定

**1. 面の要素は導出される。語彙は一つも増えない。**

- **床** は `level` の `slab` (床組み厚) が既に宣言している。階のFLの下に、その厚さで下がる。
- **天井** は `space` の `h` (天井高、既定は `level` の `h`) が既に宣言している。FLの上に、その高さで張られる。
- **屋根** は「上に空間が重なっていない床つき空間」の上に架かる。これもモデルに既にある事実の裏返しである。

`src/fabric.ts` の `slabs(model)` が三種の面を返す。ビュアーは押し出すだけで、どこに床があるか・天井があるか・屋根が架かるかを一切判断しない。

**2. 面が無い場所も、既にある事実が決める。**

- 吹抜け (`type:void`) に床は無い。**床の不在こそが吹抜けの定義**である (ADR-0006)。
- 外部空間に床も天井も無い (地面である)。半屋外に天井は無い (ADR-0007 の導出をそのまま使う)。
- **縦動線に天井は無い。**階段室・斜路の天井は上の走りに沿って傾いていて、一つの面ではない — 高さ不変量を免除したのと同じ理由である (ADR-0021 決定7)。

**3. 部分被覆に屋根が架かる。**

基壇の上に塔屋が載る建物では、塔屋が覆わない範囲が基壇屋上になる。「上に空間があるか」を真偽で判定すると、少しでも掛かった基壇に屋根が架からなくなる。覆う矩形群で座標圧縮し、覆われていないセルだけを凸片で切り取る。**基壇屋上は書かずに現れる。**

**4. 天井が室の輪郭と一致するとは限らない — これを近似として明示する。**

実際の天井は室の輪郭と一致しない。折上げ天井、梁型の下がり天井、数室にまたがる連続天井、カーテンウォール手前の見切り。**「導けるから導く」で済ませてよい範囲は、基本計画の解像度までである。**

したがって:

- **既定は生成 (導出)。**基本計画の解像度では室の輪郭 × `h` が正しい近似であり、書かせるだけの情報量が無い。
- **`ceiling:0` が唯一の逃げ道。**現し天井 (天井を張らない) は基本計画でも設計判断なので、opt out だけは今入れる。
- **作図された天井を受け取る余地を開けておく。**将来 `ceiling` の値を高さや領域の参照に広げれば、生成と作図を選べるようになる。属性の形を変えずに値だけ広げられるので、要求が出てから入れられる (ADR-0020 が `daylight` に用意したのと同じ道)。数えない分節 `area` (ADR-0003) は下がり天井の領域を運ぶ自然な置き場でもある。

**この「生成か作図か」の選択は、天井に限らず今後の面・部材すべてに効く軸である。**今回はすべて生成側に倒す。

## 代替案

**天井を書かせる (`ceiling` を第一級の要素にする)。** 実施設計の解像度では正しいが、基本計画では書くことが無い (室の輪郭と `h` 以上の情報が無い)。書ける記法にすると、書かれていない天井と「無い」天井が区別できなくなる。

**屋根を書かせる (`roof` 宣言)。** 形状 (勾配屋根・むくり) を持たせたくなった瞬間に必要になるが、いまは平屋根しか出せないので書く情報が無い。勾配屋根が要求されたら、そのときに**所与の形** (ADR-0011 の polygon と同じ立て方) として入れるのが筋である。

**床を level の slab ではなく space の属性にする。** 一室だけ床を下げる (ピット・段差) 表現ができるが、`level` が既に階の床組みを宣言しているので二重になる。段差床は要求が出てから。

## 帰結と代償

**得たもの。** 立体が建物に見えるようになった。Revit のシステムファミリの最小集合 — 壁・床・天井・屋根・階段・斜路・手すり・柱 — が揃い、**そのうち語彙を持つのは壁 (境界) と柱だけ**である。残りはすべて既にある宣言から現れる。

**代償1: 天井は近似である。**決定4に書いたとおり。折上げも下がり天井も出ない。`ceiling:0` 以外に手がない。

**代償2: 屋根は平屋根だけである。**勾配・むくり・パラペットの立ち上がりを持たない。

**代償3: 床は空間ごとに分かれる。**構造スラブは室を跨いで連続するが、ここでは空間ごとの版として出る。壁芯で切れているので見た目には連続して見えるが、**部材としては正しくない**。部材としての床が要る (数量・構造) 段になったら、空間ごとの版を統合する導出を別に持つ必要がある。

**代償4: 天井裏 (懐) は空洞のままである。**`h` と上階の `slab` の差が懐だが、そこに何も生成しない。設備の経路を持つ段になったら、この空隙が舞台になる。
