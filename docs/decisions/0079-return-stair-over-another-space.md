# Return stair over another space

The region used to tally a room can cover only part of a return stair. For a union on the
departure level, use the rectangular enclosure identified by the stair boundary on the
next level when both footprints agree on their outer limits. A bounding box alone gives
no evidence that a flight crosses the missing part. An unrelated room upstairs gives none
either. Ambiguous connections leave the run unresolved.

This extends a case rejected by RUN03 using existing muro 1.6 declarations. Keep the
single-rectangle derivation and the reading of earlier versions intact. The declared
floor regions and canonical representation remain the source for areas and occupancy.
