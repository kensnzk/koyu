# ADR-0014: 境界の既定 — 水平の「既定は壁」

日付: 2026-07-25 / 状態: 採用 (v0.10) / 起点: 外部レビュー§4.4 ([docs/reviews/](../reviews/))、方向性計画§2.3

## 文脈

垂直方向の意味論は美しかった — 「床は書かない。既定は床、例外 (stair/shaft/void) だけ宣言する」(ADR-0002/0006)。水平方向は非対称で、接する空間の境界は全て手書きし、書き忘れは警告どまりだった。外部レビューはこれを「自動導出でも必須でもない、両案の悪い中間」と正確に突いた: 形状上は接しているのにグラフに辺が無く、「valid model」の意味が曖昧になる。また「壁は空間の割付から導出される」という中核主張が、壁線の導出だけを指し、境界関係そのものは大量に手書きされる — 主張と実体に距離があった。

## 決定

**1. 接する空間の既定は壁。** 同一レベル (未特定同士を含む — 旧警告と同じ述語) で平面が接する領域つき空間の組に、宣言境界がその組に一つも無ければ、合成後に `kind:wall` の既定境界を導出する (`derived` フラグ、`deriveDefaultBoundaries` — parse/parseWithの出口で適用、冪等)。未宣言の接触は「未定義」ではなく「壁」を意味する。既定の壁は扉を持たないため通れず、描画は素の宣言wallと同一 (t既定100)。宣言は例外 (open・手すり air:1) と属性・開口のためにある — 垂直と対称になる。

**2. 導出しない場合を三つに限る。** (a) その組に宣言が一つでもあるとき (edge限定含む — pair単位の抑制。旧「宣言済みは警告なし」と同型)。(b) 領域を持たない空間 (exterior等) との組 — どの外部かの名指しが情報であり、既定は導けない。(c) 垂直 (レベルが異なる組) — 既定は床のまま (ADR-0002)。帰結として、吹抜け (type:void) の縁にも既定壁が導出される (手すり・openは宣言する) し、領域つきexteriorとの接触にも導出される (接道長に算入)。

**3. 既定境界は正準JSONに出ない。** 正準JSONは書かれた構成のみ (ADR-0013の「書かれた表記を保存」の系)。意味 (既定壁を含む) は導出後のModelが持ち、正準JSONの消費者は `deriveDefaultBoundaries` を適用してから意味を読む。

**4. 「接しているのに境界が宣言されていません」警告は廃止する。** 警告が促していた宣言は、既定の導出に置き換わった。

**5. 言語版を0.2に上げる (ADR-0017の最初の適用)。** 0.1では警告だった未宣言接触が0.2では壁になる — 意味論の変更である。0.1ファイルは意味保存の場合 (導出が起きない場合) のみ受理され、導出が起きる0.1ファイルはエラーで二択 (境界を宣言する / 0.2へ上げる) を示す。

## 代替案

**必須化 (未宣言をエラー)** は明示性が高いが記述量を増やし、垂直の既定 (床は書かない) と非対称になる — 「書かない」がkoyuの文法である。**警告の維持 (現状)** はレビューの言う悪い中間。**query時の暗黙辺 (導出せず解釈で足す)** は、check/plan/graphの全消費者に同じ暗黙知を複製する — 一度materializeして全下流が同じModelを見る方が小さい。**既定境界の正準JSON掲載**は意味等価な二つの書き方 (素wall宣言 vs 省略) のJSONを一致させられるが、「書かれた構成」の原則を破り、宣言と導出の区別を失う。

## 帰結と代償

「壁は空間の割付から導出される」が境界関係のレベルでも真になり、最小の記述 (space行だけ) が完全な意味を持つ。敵対的レビュー (6レンズ) とプロトタイプで反証を試みた: 境界重複検査・edge混在警告は構造的に発火不能、垂直検査・高さ不変量・isSemiOutdoor・light・siteは不干渉、doorsは不変 (扉なし壁は通れない)、SVGは素wall宣言と同一描画 — examples 6件で全出力 (stats/levels/light/site/doors/SVG26枚) のバイト一致を実測した。代償: (1) 既存examplesには素のwall行が1本も無く (全てt:/spec:付き)、この機能でexamplesは縮まない — 効くのは初期スケッチと最小記述。(2) 意味等価な二つの書き方 (素wall宣言 vs 省略) の正準JSONは異なる — semantic diff (ADR-0018) が実効境界集合で吸収する。(3) `graph` の隣接一覧に既定壁の行が増える (真の隣接が見える — 改善とみなす)。
