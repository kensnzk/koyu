# koyu 1.0.0 への行程

方針は [policy.md](policy.md) が、範囲の規範は [spec/scope.md](../spec/scope.md) が持つ。この頁は**残りの作業だけ**を持つ。

**1.0.0 は機能の完成ではない。壊さないと約束する面の確定である。**したがって行程は「何を作るか」ではなく「何を凍らせられる状態にするか」で切ってある。

現在は **koyu 0.16.0 / muro 1.0** である。**版は二本あり、切り離してある** ([ADR-0042](decisions/0042-two-version-lines.md)) — 言語は `muro 1.0` で確定し、実装はまだ 0.x で何も凍結を約束しない。1.0.0 を名乗るのは、八つの面が**立った**ときではなく、通しで**見た**ときである。

探求の経緯 (M0〜M1.6 の各段で何を確かめ、何を見送ったか) は [log/](log/) と [decisions/](decisions/) にある。行程表としては畳んだ — 済んだ道のりを行程表に置いておくと、残りが見えなくなる。

## 残っている作業 — 1.0.0 を名乗る前の最終確認

**面が立ったことと、面を見たことは違う。**テストが 398 件緑であることは、テストが縛っている範囲について言えるだけである。1.0.0 は引き返せないので、**縛っていない範囲を人が通しで見る** ([ADR-0042](decisions/0042-two-version-lines.md) 決定3)。0.16.0 はそのための版であり、0.x である間は何が変わっても破壊的変更ではない。

見るのは四つ。

| 面 | 何を見るか | なぜテストで足りないか |
|---|---|---|
| **MCP** | 12のツールを実際に stdio で叩き、入出力と失敗時の挙動を見る | 外へ出している面なのに、通しで動かした記録が無い |
| **文書** | spec / guide / README が**現在**を語っているか。貼られた出力が実物か (掟10) | 文の正しさは機械が読めない |
| **ugatsu** | ブラウザで実際に描かれるもの — 平面・立体・テーマ・編集 | `Form` の一致は縛れるが、**見た目**は縛っていない (それが設計である) |
| **公開面** | `npm pack` に何が入るか、CLI 全サブコマンドが実際に動くか | パッケージの中身と実行は、テストの外にある |

**確認して直したものは 0.16.x で出し、通ったら 1.0.0 を切る。**

### 直近で閉じたもの — 描かれた線が絡む四つの不整合

**規則を書き下したことが、規則の破れを見せた。**`spec/derivation.md` を書く過程で、同じ原本から二つの形が出る経路が四つ見つかり ([ADR-0040](decisions/0040-derive-reference.md) 代償4)、[ADR-0041](decisions/0041-derivation-uniqueness.md) が一つの原理 — **形は正準形の関数である** — に畳んで閉じた。

| # | 経路 | 直す前 → 直した後 |
|---|---|---|
| 1 | 外皮を切る線で、`boundary` の a/b を入れ替えると**残す側が反転する** | 16.00㎡ ↔ 14.00㎡ → **一致** |
| 2 | 線の端点の**書き順**が開口の `at:` の起点を決めるのに、正準JSONは書き順を捨てる | 正準JSONがバイト同一のまま扉 (750,2500) ↔ (2250,3500) → **一致** |
| 3 | `line` を持つ境界の**宣言順**で導出面積が変わる | 正準JSONがバイト同一のまま 27.00㎡ ↔ 22.50㎡ → **一致** |
| 4 | 診断が `drawnCut` を呼び直すため母集団が食い違い、実際に切った線に LIN03「何も切っていない」が誤報される | 4.5㎡ を落とした線に LIN03 → **出ない** |

`test/uniqueness.test.ts` が含意そのものを縛る — 正準形が等しいことを前提として確かめてから形の一致を主張するので、前提が崩れれば「この組は何も証明していない」と落ちる。

## 1.0 の後 — 伸ばす領域

**core はもう動かない。**伸ばすのは検証と表現である ([spec/scope.md §1](../spec/scope.md))。

- **検証** — 区画・避難距離・排煙・用途別の面積率。管轄が二つ目を持ったら章を割る。[spec/validation.md](../spec/validation.md) に足すだけで、言語の版は動かない
- **表現 (ugatsu)** — 寸法線・通り芯記号・建具の作図表現・縮尺・勾配屋根。**図面の精度は凍結の対象ではない**
- **外部との接続** — RDF/BOT 出力、測地、IFC からの一方向の取り込み。**コアの外に置く**

## 扱わないこと

原本における幾何 (例外は所与 — 敷地形状)。配置の仕組み (内包は座を与えない)。建築的な判定を原本の契約に含めること。実務解像度の追求 — **カバー率は価値ではない**。往復互換。曲面と自由形状。オーサリングツール。
