# 2026-07-25 — 外部レビューと意味の保証 (ADR-0013, v0.9)

外部のDSL設計レビューを受領し、指摘11件 (D-001〜D-011) を全件、最小ケースで検証した — 原文と検証・方向性の計画は [docs/reviews/](../reviews/) に収めた。10件が事実、1件 (属性の後勝ち) は仕様化済み挙動への異議。重かったのは、正準JSONが境界の向きを捨てて「swingの違う二モデルがバイト同一」になること、wall/openの矛盾宣言がcheck緑で通ること、MCPのwrite_layerが書いてから検査するため壊れた原本が残ること。

回収はADR-0013として着地 (v0.9): 正準JSONへ `a` キーを保存し宣言順に依らない正準順を定義、境界の同一性 (対+edge) の重複をエラー化、凹敷地の包含と敷地形状の妥当性検査、宣言面積の照合をcheckへ、同一行の属性重複と未対応版をエラー化、write_layerを検査先行+atomic+実体パス検査に、`model.layers` で合成の参加記録を完全に。specを現在形へ書き直し (void上側の非voidは実装どおり警告へ訂正)、リリース情報 (lockfile・CITATION・README数値) を同期してテストで守る。テスト99→114本。

レビューの残りの提案 — 診断契約、境界の既定 (接する空間の自動wall)、同一性 (任意uid)、言語版ポリシー — は次のADRの問いとして計画に積んである。
