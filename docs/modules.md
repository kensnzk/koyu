# 寸法モジュールの台帳 — muro で建物を生成するときの実寸

muro の生成で建物が「それらしく」なるかは、ほぼ**寸法を実在から取っているか**で決まる。
check は整合を守るが、寸法の現実性は守らない — 2m 幅のエレベーターも 30m デプスの貸室も緑になる。
この頁は、生成のたびに調べ直さなくて済むよう、実在の機器・慣行から取った寸法を貯める台帳である。

規範ではない (それは [spec/](../spec/README.md) の仕事)。ここにあるのは**設計の知見**で、
出典は実在の製品カタログと日本の設計慣行。例での実証は [examples/twin/](../examples/twin/main.muro) が主。

## 構造グリッド

| モジュール | 値 | 根拠 |
|---|---|---|
| 事務所・商業の基本スパン | **8,400** | 日本の大規模オフィスの最頻値 (6.4〜9.6mの中庸)。駐車3台 (2,800×3) とも割り切れる |
| 大スパン (宴会場・無柱) | 16,800〜25,200 | 基本スパンの2〜3倍で梁成を現実に収める |
| 柱寸法 | 低層 1,000 → 高層 700 角 | CFT/S造の超高層で階を追って絞る |

## 縦動線

| モジュール | 値 | 根拠 |
|---|---|---|
| エレベーター 1600kg級 かご | 2,150W × 1,600D | 実在の乗用EVの標準機種 |
| 同 昇降路 (シャフト) 1台 | 2,800W × 2,400D | かご+カウンターウェイト+躯体余裕 |
| **3室並び = 8,400 = 1スパン** | 2,800 × 3 | 台数計画がそのままグリッドに乗る — twin の全バンク。**シャフトは1機=1室で書く** (束ねると平面がEV室の実態を失う) |
| 乗場ホール (対面バンク) | 幅 4,200 | 対面2列の標準。片側バンクなら 2,700〜3,500 |
| シャフト背面帯 | 1,800 | EPS・PS・DSを収める設備帯。コア断面はこの三層 (シャフト2,400+背面1,800) で読む |
| 台数の目安 | 事務所 3,000〜4,000㎡/台、ホテル 100室/台 | 交通計算の初期値。twin: オフィス12台+SV2台、ホテル・住宅3台+SV1台 |
| 特別避難階段の塊 | **2,800 × 7,000** | 幅1,200×2列+中壁。階高4,200を蹴上180×24段で降りると踏面240×踊場で7,000要る — 6,000では RUN06 (踏面過小) になる (twin で実測) |
| エスカレーター | 幅1,200機 × 長さ = 階高×√3 ≒ 階高6,900で12,000 | 30°勾配。乗降場各2,000を足す |
| 車路スロープ | 幅 6,000 (すれ違い) / 勾配 1/6 まで | 階高4,200なら水平長 25,200 = 3スパン |

| 部位 | 階高 | 内訳 |
|---|---|---|
| 事務所基準階 | **4,200** | 天井2,800 + 懐1,400 (slab:1400 と書く) |
| 商業 (物販) | 4,800〜6,900 | 天井高3,000〜 + 厚い設備懐。1階エントランスは 6,900 (天井6,000) |
| ホテル客室・住戸 | 3,200〜4,200 | twin は事務所と同じ板に載せるため4,200のまま |
| 機械階 | 4,600〜6,000 | 熱源機器の据付高さ。**客の階数に現れない** (M1/M2 と名付ける) |
| 地下駐車場 | 3,300 (梁下2,300+) | slab:900 |

## 平面の割り

| 部位 | 値 | 根拠 |
|---|---|---|
| 事務所貸室デプス (コア→窓) | **8.4〜12.6m** | 標準9〜13m。18mを超すと執務環境も構造も破綻 — 「デカい床」はここで見抜く |
| ホテル客室 | 幅 4,200 × 奥行 8,400 ≈ 35㎡ | シティホテルの標準モジュール。**幅=スパンの1/2** で割り切る |
| 共同住宅住戸 | 幅 8,400 (1スパン) × 奥行 10〜12m | 70〜90㎡ファミリー。**窓面充足を先に検算**: 採光1/7は面積比なので、奥行10.2mで幅5.6mの窓1枚では届かない (twin ではその区画を住戸にせずラウンジにした) |
| 廊下 (中廊下) | 2,400 | ホテル・住宅の標準。事務所コア内は 2,400〜4,200 |
| 店舗モール | 幅 8,400 (吹抜含む) | 両側店舗の歩行帯+滞留 |
| 便所ブロック | 1スパンの半分 (4,200 × 8,400) 男女で1スパン | 事務所基準階の標準 |

## 収益床の現実 (レンタブル比)

- 事務所単用途の基準階レンタブル比: 70〜80%。**建物全体では 60〜70%** (1階ロビー・機械階が食う)
- 巨大複合 (twin級) は**さらに下がる**: twin の実測は延床141,449㎡に対し収益床46.7% (駐車場除き52.2%)。
  コア2本・機械階2層・ホール・宴会場・屋上緑化テラスが全部 common に積まれた正直な数字
- レンタブル比を上げたければ板を深くするのではなく**コア断面を絞る** — デプスを深くすると窓なし床が増えるだけ

## 外皮

| 部位 | 値 | 根拠 |
|---|---|---|
| カーテンウォール | 1スパン幅 (8,400) × 階高いっぱいの window で「その面はガラス」と言う | twin の CW1 (8,400×5,800) / CW2 (8,400×2,700) |
| 大開口エントランス | 4枚引き自動ドア2連 = **7,200 × 5,000** | 扉を「穿つ」のではなく開口がファサードになる寸法 |
| 住戸掃き出し | 5,600 × 2,600 (sill 200) | 採光検算とセット |
| パラペット+手すり | h 1,200 / air:1 | テラス・屋上庭園の縁。air:1 で半屋外になる |

## 使い方

新しい建物を生成するときは、まずグリッドをこの台帳から選び (基本 8,400)、
コアを「シャフト2,400 + 背面帯1,800 + ホール4,200」の断面で置き、
貸室デプスが 8.4〜12.6m に収まるように板の輪郭を決める。
**寸法を先に決めてから空間を書く** — 逆にすると check は通るが建物にならない。

台帳に無い寸法を新しく調べたら、ここに追記する。値は実在の製品・慣行から取り、
例で実証した値には例への参照を付ける。
