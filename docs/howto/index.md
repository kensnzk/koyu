# 手順 — 目的から引く

一度 `.muro` を書いたことがある人が、**やりたいことの名前から**引くための頁である。上から読む本ではない。記法を初めて見るなら [はじめての .muro](../start/index.md) を先に通すこと。

各頁は前提・手順・確かめ方の三部でできている。手順の中で使う語の定義は [リファレンス](../reference/muro/index.md) にある。
